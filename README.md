# Portafolio Académico - Tecnicatura en Programación

Repositorio público donde organizo trabajos prácticos, 
exámenes, ejercicios y proyectos desarrollados durante la carrera de programación en la UTN.

# Contenido:
- Trabajos prácticos
- Ejercicios de programación
- Exámenes y parciales
- Proyectos integradores
- Prácticas personales

# Tecnologías utilizadas:
- Python
- Git y GitHub
- SQL

# Herramientas:
- Visual Studio Code
- Google Colab
- GitHub Desktop

# Objetivo:
Este repositorio funciona como registro de aprendizaje y evolución técnica durante la carrera.  
Cada trabajo refleja prácticas relacionadas con lógica, 
programación estructurada, manejo de datos y resolución de problemas.
